# booking-automation-playwright

Project Overview
UI Testing – automated browser tests for admin pages.
API Testing – automated API endpoints verification for bookings.
Fixtures & Helpers – reusable test data, helper functions, and custom Playwright fixtures.
Clean-up & Reporting – automatically removes test data and generates test reports.

Technologies & Skills
TypeScript – strong typing for tests and helpers
Playwright – modern framework for reliable browser automation
Page Object Model (POM) – clean and maintainable test design
CI/CD Ready – easily integrated with GitHub Actions or other pipelines

Project Structure
src/pages – page objects for UI tests
src/tests/ui – end-to-end UI tests
src/tests/api – API tests
src/fixtures – test data and extended fixtures
src/helpers – reusable helpers and utilities
